# NOVARA STUDIO™: статичний сайт

Відкрийте `index.html` у браузері (подвійний клік) або завантажте всю папку на будь-який хостинг
(GitHub Pages, Netlify, Cloudflare Pages). Збирати нічого не потрібно.

## Структура
```
index.html          розмітка (головна + проєкти + вікно проєкту)
css/style.css       увесь стиль, кольори в змінних на початку файлу
js/app.js           логіка: фільтри, вікно проєкту, посилання вигляду #projects/id
data/projects.js    ПРОЄКТИ: тут додаються нові
data/site.js        слова слогана, типові кнопки категорій, тексти підказок
assets/             логотип, іконка, картинки проєктів (assets/projects/)
```

## Як додати новий проєкт
1. (Необовʼязково) Покладіть картинку в `assets/projects/`.
2. Відкрийте `data/projects.js`, скопіюйте останній блок `{ ... }`, вставте після нього через кому.
3. Змініть поля. Приклад мінімального проєкту:
```js
{
  "id": "moy-proyekt",
  "name": "Мій проєкт",
  "category": "Застосунки",
  "year": 2026,
  "description": "Короткий опис.",
  "shape": "s2",
  "colors": ["#FFD23F", "#6C4BFF"],
  "image": "assets/projects/moy-proyekt.jpg",
  "links": [{ "label": "Завантажити в App Store", "url": "https://apps.apple.com/..." }]
}
```
Нова категорія зʼявиться у фільтрах сама. Кожен проєкт має власне посилання:
`index.html#projects/moy-proyekt`.

## Реальні посилання
У полі `links` вкажіть `url`. Якщо `links` порожній, показуються типові кнопки з `data/site.js`,
які поки що відповідають підказкою «Посилання скоро буде тут». PDF з кейсом: поле `caseStudy`.
